Cards

Card, Row

Cards are made from three divs:

  • card-media
  • card-body
  • card-footer

The parent div for this card has the "card" class and the "row" class. The "row" class ensures it renders left-to-right on wider screens.

All text is inside of card-body. Icons and CTA button are inside card-footer. Icons should ALWAYS PRECEED cta buttons.

Card titles should use h3.

Icons

Icons must be contained in the "icons" div, and should be raw images. Note the backslash for the img src - this is a relative from root path to the shared icon folder.

A div with the class "icon-with-text" can be used as a sibling for the icon images. Text on these divs should be inside of a span element.

Media

<div class="media ar16x9 modal"> 
    <img src="img/example.png" alt="Modal image example"> 
</div>

Both "card-media" and "media" classes use the same helper classes for their aspect ratio, and can contain either an img or iframe. These aspect ratios should almost always be used to ensure proper formatting across devices:

  • .ar1x1
  • .ar4x3
  • .ar16x9

The "media" class has a couple of unique helpers:

  • .contain
  • .modal

".modal" makes an image clickable for a "lightbox" view, and ".contain" will change the inner image from a "fill" to a "contain." This is good for things like clear PNG's

If you want a video to open as a modal, simply wrap the inner image with an anchor to a youtube video: 

<div class="media ar4x3 modal">
    <a href="https://youtu.be/oHg5SJYRHA0">
        <img src="img/example.png" alt="Modal video example">
    </a>
</div>

If you'd rather the video play within the media div and not open as a modal, simply drop the iframe inside the media class: 

<div class="media ar4x3">
    <iframe src="https://www.youtube.com/embed/oHg5SJYRHA0?si=neWpcgDi-oQM7nj5" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>
</div>

Grids

Time for the Big stuff! Actually just kidding, these grids are super easy. Just make a div with the "grid" class and then make divs for each child. These child divs can contain anything a normal div would! There's a few style modifiers to keep in mind:

  • --cols: x;
  • --collapse-to: x;
  • grid-column: span x;

By default, grids are two columns wide and collapse to a single column on smaller screens: 

<div class="grid">

    <div class="media ar1x1">
        <img src="img/example.png">
    </div>

    <div class="media ar1x1">
        <img src="img/example.png">
    </div>

</div>

This behaviour can be modified by style attributes: 

<div class="grid" style="--cols: 3; --collapse-to: 3;">

    <div class="media ar1x1">
        <img src="img/example.png">
    </div>

    <div class="media ar1x1">
        <img src="img/example.png">
    </div>

    <div class="media ar1x1">
        <img src="img/example.png">
    </div>

</div>

"--collapse-to" should always be lower than or equal to "--cols".

If you want a grid item to span across multiple columns, simply add an inline style to that element: 

<div class="grid" style="--cols: 3; --collapse-to: 3;">

    <div class="media ar16x9" style="grid-column: span 2;">
        <img src="img/example.png">
    </div>

    <div class="media ar1x1">
        <img src="img/example.png">
    </div>

</div>

That still doesn't look quite right, though! If you want these elements to automatically resize to fit on one line, just remove the aspect ratio helper from the element that can change more easily. 

<div class="grid" style="--cols: 3; --collapse-to: 3;">

    <div class="media ar16x9" style="grid-column: span 2;">
        <img src="img/example.png">
    </div>

    <div class="media">
        <img src="img/example.png">
    </div>

</div>
